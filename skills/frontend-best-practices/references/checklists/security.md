# 安全检查清单

## 概述

本文档提供前端安全审查的检查清单，基于 OWASP Top 10 和行业最佳实践。

---

## 一、输入验证与输出编码

### 输入验证

- [ ] 所有用户输入都经过验证
- [ ] 使用白名单验证而非黑名单
- [ ] 验证类型（string、number、email 等）
- [ ] 验证长度（最小/最大）
- [ ] 验证格式（正则表达式）
- [ ] 验证范围（数值边界）
- [ ] API 请求参数验证

### 输出编码

- [ ] HTML 上下文编码
- [ ] JavaScript 上下文编码
- [ ] URL 上下文编码
- [ ] CSS 上下文编码
- [ ] 避免使用 dangerouslySetInnerHTML
- [ ] 使用 DOMPurify 净化 HTML

---

## 二、XSS 防护

### 存储型 XSS

- [ ] 用户输入在服务端净化
- [ ] 输出时再次编码
- [ ] 富文本编辑器使用安全库

### 反射型 XSS

- [ ] URL 参数验证
- [ ] 搜索结果转义
- [ ] 错误消息转义

### DOM 型 XSS

- [ ] 避免 eval、new Function
- [ ] 避免 innerHTML
- [ ] 使用 textContent 而非 innerHTML
- [ ] URL 参数处理安全

### CSP 配置

- [ ] CSP 头已配置
- [ ] 内联脚本限制
- [ ] 外部脚本白名单
- [ ] 防止代码注入

---

## 三、CSRF 防护

### Token 验证

- [ ] CSRF Token 生成
- [ ] 表单包含 Token
- [ ] 请求头包含 Token
- [ ] Token 验证逻辑正确

### Cookie 安全

- [ ] httpOnly 属性设置
- [ ] Secure 属性设置（生产环境）
- [ ] SameSite 属性配置
- [ ] 不在 URL 中传递敏感信息

### 双重提交 Cookie

- [ ] Cookie 和表单 Token 匹配
- [ ] 安全比较（时序安全）

---

## 四、敏感数据处理

### 数据脱敏

- [ ] 日志中脱敏
- [ ] 界面显示脱敏
- [ ] API 响应脱敏
- [ ] 导出数据脱敏

### 存储安全

- [ ] 不在 localStorage 存储敏感信息
- [ ] 不在 sessionStorage 存储敏感信息
- [ ] 加密存储（如必须）
- [ ] 定期清理过期数据

### 传输安全

- [ ] 使用 HTTPS
- [ ] API 使用加密
- [ ] 敏感数据加密传输

---

## 五、身份验证与会话管理

### 密码处理

- [ ] 密码不在前端存储
- [ ] 密码强度验证
- [ ] 密码加密传输
- [ ] 密码重置安全流程

### 会话管理

- [ ] 会话超时设置
- [ ] 会话刷新机制
- [ ] 登出时清除会话
- [ ] 多设备登录限制（可选）

### 令牌管理

- [ ] Token 存储安全
- [ ] Token 过期处理
- [ ] Token 刷新机制
- [ ] Token 撤销机制

---

## 六、API 安全

### 请求验证

- [ ] 请求参数验证
- [ ] 请求头验证
- [ ] 请求体验证
- [ ] 文件上传验证

### 速率限制

- [ ] API 速率限制
- [ ] 登录尝试限制
- [ ] 注册限制
- [ ] 暴力破解防护

### 错误处理

- [ ] 不暴露内部错误
- [ ] 错误日志安全
- [ ] 用户友好错误消息
- [ ] 错误码标准化

### 访问控制

- [ ] 认证检查
- [ ] 授权检查
- [ ] 资源隔离
- [ ] 权限验证

---

## 七、依赖包安全

### 依赖管理

- [ ] 依赖来源可信
- [ ] 版本锁定
- [ ] 定期更新
- [ ] 最小权限原则

### 安全审计

- [ ] npm audit 运行
- [ ] 已知漏洞检查
- [ ] Snyk 或其他工具扫描
- [ ] CI/CD 集成安全检查

### 第三方代码

- [ ] 审查第三方脚本
- [ ] 使用 SRI（子资源完整性）
- [ ] 限制 iframe 使用
- [ ] 沙箱隔离

---

## 八、客户端安全

### 安全头

- [ ] X-Frame-Options 配置
- [ ] X-Content-Type-Options 配置
- [ ] X-XSS-Protection 配置
- [ ] Strict-Transport-Security 配置
- [ ] Referrer-Policy 配置
- [ ] Permissions-Policy 配置

### 调试信息

- [ ] 生产环境移除 console.log
- [ ] 禁用开发者工具（可选）
- [ ] 移除源代码映射（生产环境）
- [ ] 不在错误消息中暴露敏感信息

### 代码安全

- [ ] 无硬编码密钥
- [ ] 无硬编码密码
- [ ] 无调试代码残留
- [ ] 环境变量正确使用

---

### 数据保护

- [ ] 符合 GDPR（如适用）
- [ ] 用户数据收集告知
- [ ] 数据删除机制
- [ ] 隐私政策

### 安全培训

- [ ] 开发人员安全培训
- [ ] 安全编码实践
- [ ] 社会工程防范
