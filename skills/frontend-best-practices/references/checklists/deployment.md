# 部署前检查清单

## 概述

本文档提供前端应用部署前的完整检查清单，确保生产环境部署的安全性和稳定性。

### 环境变量

- [ ] 生产环境变量已配置
- [ ] API URL 正确配置

- [ ] 无硬编码配置
- [ ] 环境变量文档更新

### 密钥管理

- [ ] API 密钥已配置
- [ ] 第三方服务密钥配置

### 多环境支持

- [ ] 开发环境配置

- [ ] 生产环境配置
- [ ] 环境隔离

## 二、构建检查

### 构建成功

- [ ] npm run build 执行成功
- [ ] 无 TypeScript 类型错误

- [ ] 构建输出正常

### 构建产物

- [ ] 产物大小合理

- [ ] 资源路径正确
- [ ] Source Map 生成（可选，生产禁用）

### Bundle 分析

- [ ] Bundle 大小检查

- [ ] Tree Shaking 生效

## 三、性能检查

### Core Web Vitals

- [ ] LCP < 2.5s
- [ ] FID < 100ms
- [ ] CLS < 0.1
- [ ] Lighthouse 得分 > 90

### 资源优化

- [ ] 图片已优化（WebP/AVIF）
- [ ] 字体已优化
- [ ] CSS/JS 已压缩
- [ ] 关键资源已内联

### 加载性能

- [ ] 首屏加载时间 < 3s

- [ ] 缓存策略配置
