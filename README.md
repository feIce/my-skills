# my-skills

本仓库包含多个实用的技能模块，用于辅助开发工作。

## 技能列表

### 1. frontend-best-practices

**描述**：全面覆盖前端开发最佳实践，包含代码规范、性能优化、安全防护、可访问性等十大核心领域。

- [查看详情](skills/frontend-best-practices/SKILL.md)

**核心领域**：
- 代码规范
- 组件开发
- 性能优化
- 安全防护
- 可访问性
- 跨浏览器兼容
- 工程化配置

**适用技术栈**：React / Next.js、TypeScript、Vue.js、JavaScript (ES6+)、Tailwind CSS

### 2. frontend-modification-security

**描述**：前端修改安全约束。当用户修改 Vue/React 组件、调整页面布局、创建覆盖层/蒙版组件时激活。

- [查看详情](skills/frontend-modification-security/SKILL.md)

**核心领域**：
- 数据绑定保护
- 布局一致性规范
- 覆盖层定位规范

### 3. react-snake-game

**描述**：提供基于 react-pixi-snake-game 的 React 贪吃蛇游戏学习资源和示例代码。

- [查看详情](skills/react-snake-game/SKILL.md)

**核心特性**：
- 完整的贪吃蛇游戏实现
- 高性能 PixiJS 渲染
- TypeScript 类型安全
- 面向学习的代码结构

**技术栈**：React 18+、TypeScript、PixiJS、Vite
